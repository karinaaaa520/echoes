## 1. F-1 关卡提示系统

### 1.1 先解决字体（这是真正的前置阻塞）

Godot 内置字体不含中日韩字形，直接显示中文会是一排方块。处理过程：

1. 先尝试开源像素字体「方舟像素 12px」（OFL）：GitHub release 资源反复断流（3 次尝试，最大只拿到 10MB/36MB，`curl` 报 exit 56），放弃。
2. 改用本机已安装的 **Noto Sans CJK SC**（`© 2014-2021 Adobe`，**SIL OFL 1.1**，允许随作品分发与子集化）。
3. 用 `fontTools pyftsubset` 只保留游戏用到的 **142 个字形**（四条提示 + 界面英文/数字）：

```
echoes/art/fonts/hint-subset.otf   14.6 KB
echoes/art/fonts/OFL.txt           4.4 KB（版权声明 + OFL 1.1 全文）
```

4. 校验：把子集字体的 cmap 与提示文本逐字对比，**缺字 0 个**（脚本输出「缺字: 无」）。
5. 运行时关掉抗锯齿与次像素定位（`antialiasing=NONE`、`subpixel_positioning=DISABLED`、`hinting=NONE`），让 12px 的字保持硬边，和像素画面一致。

### 1.2 提示条设计

```
UI/Hint（Control，锚在底部，高 22px，modulate.a 控制淡出）
├── Bg   深色底 #0b0b0e / 88% 不透明
├── Top  顶部 1px 分隔线 #4f4770
└── Text 12px、居中、单行
```

- **时机**：`_show_hint()` → alpha=1 → 停 2.4 秒 → 0.6 秒淡出。
- **触发点**：① 载入关卡（含自动切关）② 按 R 重置 ③ 通关面板出现时立刻收起（避免两层文字叠在一起）。
- **文案**：仍是每关一句中文，但为了单行显示改短了（原来最长 43 字要折两行，第二行会被屏幕底边裁掉）：

| 关卡 | 提示文案 | 字数 |
|---|---|---|
| L1 | 方向键移动。影子会重复你上一拍走的方向。 | 20 |
| L2 | 有块板你进不去，但影子在里面。 | 15 |
| L3 | 影子被关在壁龛里，先走它要走的方向。 | 18 |
| L4 | 两块板都在壁龛里，左边踩完再去右边。 | 18 |

### 1.3 不遮挡：用几何证明，而不是"看起来没挡住"

提示条占 158~180 的像素带。四关地图在整数倍缩放后，"最后一行可玩格"的底边分别是：

```
L1 138 ≤ 158   L2 122 ≤ 158   L3 138 ≤ 158   L4 130 ≤ 158
```

也就是说提示条只压在各关最底下的**墙行**上，从不盖住本体、影子、压力板、钥匙、门或出口。这条已经写成断言（`test_hint` 第 [5] 组），关卡以后改尺寸也会被它挡住。

## 2. F-3 地图显示比例

### 2.1 做法

`WorldView` 不再固定 1×，而是按地图实际像素尺寸取**最大整数倍**：

```gdscript
static func max_zoom(map_px, view, margin := 3.0) -> int:
    var avail := view - Vector2(margin, margin) * 2.0
    return maxi(1, int(minf(avail.x / map_px.x, avail.y / map_px.y)))
```

- 只取整数倍 → 不会出现 1.5× 那种半像素拉伸。
- 先算缩放再定位（`position = ((view - map_px*zoom)/2).floor()`）→ 中心也落在整数像素上。
- 角色是 `World` 的子节点，跟着一起缩放，**碰撞与输入完全不受影响**（仍是格子坐标）。

### 2.2 结果：只有 L1 能变大（这是数学结果，不是偷懒）

| 关卡 | 地图像素 | 1× | 2× 是否放得进 320×180 | 采用 |
|---|---|---|---|---|
| L1 | 112×80 | 要 112×80 | 224×160 ✅ | **2×** |
| L2 | 144×96 | 144×96 | 288×192 ❌ 高出 12px | 1× |
| L3 | 176×128 | 176×128 | 352×256 ❌ | 1× |
| L4 | 176×112 | 176×112 | 352×224 ❌ | 1× |

在"16px 图块 + 整数倍 + 不裁切"三条约束下，L2/L3/L4 的 2× 都会超出 180 的高度，**只能 1×**。
要让它们也变大，只有三条路：改地图尺寸（改关卡内容）、改图块大小（破坏像素对齐）、改逻辑分辨率（牵连整个 UI）——都超出本轮范围。

因此本轮的实际收益是 **L1 从占屏 35%×44% 提升到 70%×89%**，另外三关保持原样但**拿到了自动放大的能力**（以后地图改小会自动放大，不用改代码）。

测试里对四关都断言了两件事：① 缩放后不超过视口 ② 再放大一倍必然溢出（证明取到的是最大值而不是随便取）。

### 2.3 H5 的整数倍

浏览器实测：1280 宽的画布里，游戏区域恰好 960 宽（两侧各 160px 黑边），即 **3× 整数缩放**，没有非整数拉伸：
像素采样 `x=4/80 → #000000`（黑边），`x=160/640 → #0b0b0e`（提示条）。

## 3. 视觉可读性

### 3.1 墙与地面：把明暗关系反过来

改前墙比地**亮**（`#3d3d49` vs `#23232b`）。放大到 2× 后问题被放大：整块墙像"平台"，深色房间像"洞"。

改后墙比地**暗**：

| 元素 | 改前 | 改后 |
|---|---|---|
| 地面 | `#23232b` | `#30303c` |
| 地砖缝 | `#1b1b21` | `#262633` |
| 墙体 | `#3d3d49` | `#20202a` |
| 墙顶面 | `#55555f` | `#3c3c4a`（+ `#191922` 阴影线） |
| 壁龛地砖 | 与地面相同 | `#221f2c` + 边框 `#5b4f7a` |

现在"亮的区域 = 能走的地方"符合直觉，角色/机关都落在亮底上，对比度更高。

### 3.2 壁龛：让"进不去"看得见

`WorldView.sealed_cells()` 在载入时从本体起点泛洪（门按开着算），把所有**走不到的地格**标记出来，
画成偏冷偏暗的地砖，并只在"与外界相邻"的那一侧画 1px 亮边 —— 读作"这块被封住了"。

实测覆盖：L1 0 格（开放房间）、L2 4 格（2×2 方孔）、L3 5 格、L4 5 格。
这一条同时被 4 条断言盯着（含"必须有必需的板落在封闭区里"）。

### 3.3 压力板 / 出口的双态

| 机关 | 关闭/未触发 | 开启/已触发 |
|---|---|---|
| 压力板 | 1px 细空心环，暗青 `#2f7f6e` | 实心圆盘 `#3fbfa3` + 亮心 `#a8f2dd`，**整格地砖同时提亮** |
| 出口 | 暗青边框 + 中间一道横杠 | 亮青边框 + **四角加重块** + 地砖提亮 |

改前也用"空心/实心"区分，但两者亮度接近；现在多了一档"地砖提亮"，在 1× 下也能一眼分清。

### 3.4 角色

- 本体：从 `draw_circle`（矢量圆）改为 `PixelDraw.disc()` 逐行整数矩形拼出的**像素圆盘**，加 2×2 高光块。
  这样放大到 2× 时边缘仍是硬像素，不会出现"一个光滑的圆漂在方块世界里"。
- 影子：方形 + 1px 亮边框 + 内层暗心，和圆盘在形状、亮度上都不同（灰度截图也能区分）。

### 3.5 通关面板

- 遮罩从 78% 提到 **84%**，地图只留淡淡一层。
- 标题 24px + 2px 投影（`CHAPTER COMPLETE` 自动降到 18px 防溢出）。
- 行距 5 → 6，副标题统一 12px（与提示同一套字号，视觉更统一）。
- 通关时提示条立刻收起，不会出现两层文字。

## 7. 下一阶段建议

1. **给提示配一个"再来一次"的机会**：现在提示 3 秒后消失且不再出现。可以让按 `R` 时不只重开、也重放提示（已实现），再补一个"站住不动 5 秒重新提示"会更友好。
2. **把 N-2 的三选一交给你**：要么接受现状（只 L1 放大），要么允许我把 L2 缩到 8×5（改关卡），要么把逻辑分辨率降到 256×144（牵连 UI）。我倾向第一个。
3. **音效**是最缺的一环：现在四关是纯静的，踩板、开门、通关都没有声音。比赛评分里"完成度"很吃这个。
4. 提交前补：真实 Release 包 + 60~90 秒录屏。
