三个里程碑：

- **T3**：影子踩亮 b（左齿），同时本体踩亮 a
- **T9**：本体撞锁门——本拍**开门但不移动**
- **T11→T12**：本体在 (5,3) 按 D 撞在下方隔墙上**原地不动**，但这个 D 被记录；第 12 拍影子执行它，落到 p（右齿）→ 三块板齐 → 出口开启

第 11 拍是这一关的"题眼"：**一次看不见效果的按键，换了影子一步**。

## 4. 影子必要性（三类证据）

### 4.1 结构

```
【4 双重回响】影子必要性审计
  本体可达 33 格；本体**结构上踩不到**的板: ['b', 'p']
```

壁龛 5 格（`(6,5)(7,5)(8,5)` + `(6,6)=b` + `(8,6)=p`）与本体可达的 33 格**没有一条边相连**。
`exit_needs = [a,b,p]`，其中两块只在壁龛里 —— 不使用影子就永远凑不齐条件。

### 4.2 反事实搜索

```
反事实 1（影子不存在）      : ✅ 不可通关
反事实 2（影子不触发压力板）: ✅ 不可通关
```

引擎侧还补了三组对照（`test_level4` 第 [4] 组）：

```
[PASS] 对照组（只要 a）本体单独可以通关     ← 同一张图去掉 b/p 就能通
[PASS] 只要 b 时本体单独不能通关
[PASS] 只要 p 时本体单独不能通关
```

后两条说明**两块影子板各自都是必需的**，不是"有一块就够"。

### 4.3 因果（引擎逐拍）

```
[PASS] 第 11 拍本体原地不动（撞墙）
[PASS] 但方向 D 仍被记录给影子
[PASS] 第 12 拍影子执行这个 D，落到 p
[PASS] 换掉那一拍（D→R），p 不亮 / 出口不开 / 17 拍走完也过不了关
```

## 7. 关于"比第三关更难"的诚实说明

两关最短解都是 17 拍。难度提升体现在**状态复杂度**而不是步数：

| 维度 | 第 3 关 | 第 4 关 |
|---|---|---|
| 影子专属板 | 1 | **2** |
| 影子路线 | 4 步，单向钩形 | **6 步，需往返**（左→下→上→右→右→下） |
| 玩家要追踪的量 | 影子到没到钩底 | **影子去过哪块板、还差哪块** |
| 关键洞察 | "我得先走影子要走的方向" | **"我按的键是给影子的，哪怕我自己动不了"** |

我有意没有把地图做大、把路线拉长 —— 那只会增加按键次数，不增加思考。
但必须承认：**如果你希望第四关在步数上也明显更长（例如 22~25 拍），现在这版不满足**。
需要的话可以调大壁龛（增加一条齿）或把钥匙挪远，代价是节奏变拖。
