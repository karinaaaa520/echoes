## 3. 第一关 → 第二关的切换实现

### 3.1 三种通关结局

`_show_win()` 现在按当前关卡分三支：

| 场景 | 标题 | 关卡行 | 提示行 | 后续 |
|---|---|---|---|---|
| 机关测试室（Debug 自检） | YOU WIN | LEVEL 1 COMPLETE | PRESS R TO RESTART | 停在这里，**不跳关** |
| 第 1 关（还有下一关） | YOU WIN | LEVEL 1 COMPLETE | NEXT LEVEL... | 1 秒后自动进第 2 关 |
| 第 2 关（最后一关） | CHAPTER COMPLETE | LEVEL 2 COMPLETE | PRESS R TO RESTART | 停留，R 回第 1 关 |

标题字号按长度自适应（≤8 字符用 18px，否则 14px），否则 `CHAPTER COMPLETE` 会顶满 320px 的屏宽。

### 3.2 自动推进的防串场设计

自动切关最大的风险是"上一关的回调把下一关带跑"。用**令牌**解决：

```gdscript
var _advance_token := 0

func _schedule_next_level() -> void:
    _advance_token += 1
    var token := _advance_token
    await get_tree().create_timer(AUTO_ADVANCE_SEC).timeout
    if token != _advance_token:
        return                       # 期间按过 R 或已经切过关 → 放弃
    if resolver == null or not resolver.won:
        return
    start_level(level_index + 1)
```

同时：

- `_load()` 每次都会 `_advance_token += 1` —— 任何一次切关都会让在途的定时器失效。
- `_on_reset_requested()` 也会 `+= 1` —— **1 秒窗口内按 R，不会被强行带去第二关**（第 8 节场景 E 实测）。
- `_show_win()` 由动画结束回调触发，而不是在 `step()` 里直接调用，所以不会出现"角色还在滑行就切关"。

### 3.3 "完整重置"是怎么保证的

切关不是"把旧状态清一遍"，而是**新建一个 `TurnResolver`**：

```gdscript
resolver = TurnResolver.from_level(world.level)
```

`from_level()` 内部调用 `reset()`，一次性把十项状态归位。加上视图与输入层的两个动作：

| 要求重置的项 | 由谁负责 |
|---|---|
| 本体 / 影子位置 | `reset()` + `world.snap_actors()` |
| 上一拍待执行方向 | `reset()`（`pending = ZERO`） |
| 回合计数 | `reset()`（`turn = 0`） |
| 钥匙 / 门 / 压力板 / 出口 | `reset()`（全部重建为空 / 按 `exit_needs` 重新判定） |
| 通关状态 | `reset()`（`won = false`） |
| 输入缓冲 | `router.cancel_pending()` |
| 动画锁 | 动画已结束才切关；`snap_actors()` 内再 `stop_animation()` 兜底 |

测试第 7 组用"先打通第一关、再建第二关对象"的方式验证了这一点：第二关的 `turn=0`、`pending=ZERO`、`won=false`、各机关集合为空。

## 4. 第二关机关运行结果（逐拍）

最短解 `R R R U R R R`，7 拍。以下来自实机日志（Debug 构建）：

| 拍 | 输入 | 本体 | 影子 | 机关事件 |
|---|---|---|---|---|
| 1 | R | (1,1)→(2,1) | (3,3) 停（无历史指令） | — |
| 2 | R | (2,1)→(3,1) | (3,3)→(4,3) | — |
| 3 | R | (3,1)→**(4,1) 板 a** | (4,3)→(5,3) | **压板 a** |
| 4 | **U** | (4,1) **撞墙不动** | (5,3)→**(6,3) 板 b** | **压板 b → 出口开启** |
| 5 | R | (4,1)→(5,1) | (6,3)→(6,2) | 离开 a，锁存保持 |
| 6 | R | (5,1)→(6,1) | (6,2)→(7,2) | — |
| 7 | R | (6,1)→**(7,1) 出口** | (7,2) 撞墙停 | **★WIN** |

第 4 拍是本关的核心：本体朝上撞墙**白等一拍**，影子趁机踩到 b，两块板在同一拍同时成立，出口立即开启。这正是第 1 关教过的"撞墙也是时间的一步"，在第二关第一次被用作解谜手段。
