## 2. 问题复现（先量化，再改）

旧地图：

```text
#########
#P..a..E#
#.......#
#..S..b.#
#########
```

用 `docs/tools/level_check.py` 的模型跑（`python3` 直接调用，节选）：

```
旧第二关 最短解: 6 拍 R R R R R R
旧第二关 本体单独: 可通关 R R R D D R R U U R
旧第二关 可达状态 893 死局 396
```

两条结论：

1. **按住右 6 拍就通关**。原因是 `b − a = (2,2)` 恰好等于影子起点相对本体的偏移，
   本体的第 3、4 拍自然把影子带到 b 上 —— 影子只是"顺路"，玩家不需要理解它。
2. **本体单独也能通关**（9 拍）。两块板都在本体可达区域内，所以"影子"在这关连必要条件都不是。

这与你试玩时的判断一致：影子没有成为解谜要素。

## 3. 新设计：2×2 方孔

```text
#########
#Pa....E#
#....##.#
#...#.S##
#...#b.##
#########
```

| 元素 | 坐标 | 说明 |
|---|---|---|
| 本体 P | (1,1) | 左上角 |
| 板 a | (2,1) | 本体往右走一步就踩到（教学：板会亮） |
| 出口 E | (7,1) | 右上角，需要 a + b |
| 影子 S | (6,3) | **方孔里**，2×2 的右上格 |
| 板 b | (5,4) | 方孔左下格，与影子**斜对角** |

方孔 = `(5,3)(6,3)(5,4)(6,4)` 四格，四周全封：左 (4,3)(4,4)、右 (7,3)(7,4)、上 (5,2)(6,2)。
本体可达 18 格，方孔 4 格，两个连通域**没有一条边相连**。

**为什么这样就能教会玩家**：

1. 玩家先往右走 → 踩亮 a → 继续往右到出口 → **出口不开**（缺 b）。这是"任务清单"式的提示。
2. 环顾地图，会看到 b 在墙里的方孔中，而**自己的影子也在里面**。
3. 玩家随便走几步会发现影子跟着自己动（**慢一拍**）。
4. 方孔里 b 与影子是斜对角，直接"斜着走"不存在，必须**先下后左**或**先左后下** —— 两条都成立，
   所以新手不会卡死在"顺序唯一"上（这是刻意留的宽容度）。
5. 一旦踩亮 b，出口开，玩家回身走到出口。

**四个问题自查（对应任务书 §一）**：

| 问题 | 答案 |
|---|---|
| 本体单独能否通关 | 不能 —— b 在密封方孔里（§4.1） |
| 影子不存在能否通关 | 不能 —— 反事实搜索无解 |
| 影子不能压板能否通关 | 不能 —— 同上 |
| 是否必须考虑影子的位置/延迟 | 是 —— 必须知道影子停在方孔哪一格，才知道下一步该按 D 还是 L；而它的移动总是晚一拍 |

## 4. 验证（BFS 全状态搜索）

### 4.1 结构：b 本体不可达

`level_check.py` 的 `player_reachable()`（门按"全开"算，最宽松）：

```
【2 两处微光】影子必要性审计
  本体可达 18 格；本体**结构上踩不到**的板: ['b']
```

**4.2 反事实一：影子完全不存在**

```
反事实 1（影子不存在）      : ✅ 不可通关
```

**4.3 反事实二：影子在场上但不触发压力板**

```
反事实 2（影子不触发压力板）: ✅ 不可通关
```

对照组（把出口条件改成只要 a）：本体单独立刻可通 —— 证明卡点确实来自 b，而不是地图被写死成走不通。

### 4.4 最短解与死局

```
顺序结算（引擎实现）: ✅ 最短  9 拍  D L U R R R R R R
同时结算（备选设计）: ✅ 最短  9 拍  D L U R R R R R R
可达状态 561 个，其中死局 0 个
```

两种结算假设下解相同，说明本关不依赖实现细节。
**死局 0** 意味着玩家怎么乱走都不会进"只能按 R"的局面。

### 4.5 引擎侧复算（不是只看模型）

`tests/test_level2.gd`（新增 45 条断言）用真实 `TurnResolver` 逐拍跑同一条解，
每拍的本体 / 影子坐标都与模型输出写成常量比对：

```
[PASS] 9 拍位置全部与参考模型一致
[PASS] 第 3 拍影子踩亮 b
[PASS] 第 4 拍本体踩亮 a
[PASS] 第 9 拍通关
[PASS] 只按右能踩亮 a
[PASS] 但 b 永远不会亮
[PASS] 站在出口上也过不了关（这就是旧版的设计漏洞）
```

最后三条就是直接针对旧版漏洞写的回归断言：**按住右走 12 拍，a 亮、b 不亮、站在出口也不通关**。
