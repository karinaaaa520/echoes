打开「终端」应用，把这四行一次性粘进去回车：



- 不需要 Nginx / Apache / Node

## C. Mac 本机启动

### 方式一：终端启动（推荐，最快）

**第 1 步**：打开终端

按 `Command + 空格`，输入 `终端`（或 `Terminal`），回车。

**第 2 步**：进入导出目录

```bash
cd /Users/czh/WorkBuddy/影迹/exports/web-test
```

> 小技巧：输入 `cd ` 之后，可以直接把 Finder 里的 `web-test` 文件夹**拖进终端窗口**，路径会自动补全，不用手打。


成功的话会显示：

```
Serving HTTP on :: port 8000 (http://[::]:8000/) ...
```

**这个窗口不要关。** 关掉就等于停服务器。后面可以最小化。

## D. 浏览器运行

### D.1 用哪个浏览器

**推荐 Chrome**（本次就是用它验证的，Chromium 内核的 Edge 同理）。

Firefox 理论上也支持（单线程构建不需要特殊响应头），但**本次没有实测**。Safari **未测试**，如果遇到问题优先换 Chrome。

### D.2 访问地址

在地址栏输入：

```text
http://localhost:8000
```

注意：

- 必须是 `http://`，不是 `https://`
- 端口是 `8000`，跟启动服务器时的数字一致
- 不需要加 `/index.html`，服务器会自动返回

### D.3 怎么开始游戏

**不需要点任何按钮。** 页面加载完（Godot 蓝色 logo + 进度条走完）后会自动进入第一关。

等待时间取决于机器，第一次约 3～5 秒（要下载并解码 38MB 的 wasm），之后浏览器有缓存会快很多。

如果画面出现了但按键没反应，**在游戏画面上点一下**，确保键盘焦点在画布上。

### D.4 操作方式

| 操作 | 键位 |
|---|---|
| 移动 | `↑` `↓` `←` `→` 或 `W` `A` `S` `D` |
| 重置本关 | `R` |
| 通关后 | 等约 1 秒自动进下一关；最后一关显示 `CHAPTER COMPLETE` 后按 `R` 回第一关 |

每按一次方向键推进一个回合：**影子先动（重复你上一拍的方向），本体后动**。

### D.5 怎么关闭游戏

1. 关闭浏览器标签页（或整个浏览器）
2. 回到终端窗口按 `Control + C` 停掉服务器（见 E 节）

## E. 停止服务器

1. 回到**正在运行服务器的那一个终端窗口**
2. 按 **`Control + C`**
3. 看到命令提示符重新出现，说明已停止（有时会显示 `Keyboard interrupt received, exiting.`）
4. 直接关掉浏览器页面即可

**如果不停止会怎样**：服务器会一直占用 8000 端口。下次再启动会报 `Address already in use`。解决办法见 F.6。

## F. 常见问题

### F.1 页面打不开 / 显示「无法访问此网站」

按顺序排查：

1. **终端里服务器还在跑吗？** 窗口是否被关掉了？重新 `python3 -m http.server 8000`。
2. **地址对不对？** 必须是 `http://localhost:8000`，不要输成 `localhost:8000/index.html`（虽然也能开，但容易和端口搞混）。
3. **端口被占用？** 见 F.6。
4. 试试 `http://127.0.0.1:8000`，有时 IPv6 解析会抽风。

### F.2 页面打开了，但一直黑屏 / 停在进度条

- **先等够 10 秒**。38MB 的 wasm 首次加载需要时间，慢机器上更久。
- 按 `Command + Shift + R` 强制刷新（清缓存重新下载）。
- 看是不是只拷了 `index.html`——`index.wasm` 和 `index.pck` 必须和它放在同一目录。
- 打开控制台（见 F.4），如果看到 `Failed to fetch` 或 `404`，基本就是文件缺失。

### F.3 按键没反应 / 只有鼠标能动

1. **在游戏画面上点一下**，让焦点回到画布。
2. 确认没有别的窗口抢焦点（比如终端窗口在最前面时按键会进终端）。
3. 如果是 Mac 笔记本外接键盘，确认 `Fn` 锁没有把方向键变成别的功能。
4. 输入法切到英文（中文输入法可能吞掉字母键 `WASD`）。

### F.4 想看看浏览器有没有报错

1. 在页面上按 `F12`（或 `Command + Option + I`）
2. 切到 **Console** 标签
3. 正常情况下应该**没有任何红色错误**

本次实测的控制台输出：**0 个 JS 异常、0 条 error 级日志**。

常见红字含义：

| 红字 | 含义 | 处理 |
|---|---|---|
| `Failed to load resource: 404` | 有文件没拷全 | 检查 B.2 的 9 个文件是否都在 |
| `WebGL2 not supported` | 显卡/浏览器不支持 | 换 Chrome，或在 Chrome 设置里开启硬件加速 |
| `SharedArrayBuffer is not defined` | 用了线程版模板 | 本项目不会出现（单线程构建） |

### F.5 改了代码怎么重新导出

改完 `echoes/` 里的东西后，在**任意目录**执行这一条（路径都是绝对的）：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path /Users/czh/WorkBuddy/影迹/echoes --export-release "Web" /Users/czh/WorkBuddy/影迹/exports/web-test/index.html
```

看到 `[ DONE ] savepack` 就是成功，退出码为 0。然后浏览器按 `Command + Shift + R` 强刷。

> 这条命令本次已经实测跑通两次。

### F.6 换一个端口

把 `8000` 换成别的数字即可，比如 `8080`：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

如果提示 `Address already in use`，说明 8000 还被别的程序占着。查是谁占的：

```bash
lsof -nP -iTCP:8000 -sTCP:LISTEN
```

要么杀掉那个进程，要么直接换端口。

### F.7 能不能直接双击 index.html

**不能。** 浏览器出于安全限制，禁止 `file://` 协议加载 WebAssembly，双击只会白屏。必须用 HTTP 服务器。

### F.8 能不能发给别人玩

当前是本地服务器，只有你这台机器能访问 `localhost`。要发给别人需要把 `exports/web-test/` 整个目录传到静态托管（Netlify / Vercel / itch.io 等），那是后续阶段的事，本次不涉及。
